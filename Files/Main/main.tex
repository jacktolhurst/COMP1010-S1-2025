\headerbox{Introduction\hspace{0.15cm} $\vcenter{\hbox{\includegraphics[width=0.015\linewidth]{Bulb.png}}}$}{name=introduction,column=0,row=0}{

Software Development is widespread across the IT field, with the sole purpose of harnessing the resources of a computer system to provide useful functionality for the user. Software is used for many purposes, from controlling file systems, to games, to creative arts. However, when software is deployed in a specialized environment, this is a Specialized Software System, deployed for niche applications and often developed by specialized teams. For example, Microsoft SharePoint has a Specialised Software System in the form of a Database. Within a specific deployment, developers can focus on features, algorithms, and implementations that benefit the application, which may increase productivity of the host system.
}

\headerbox{System Architecture and Modelling \hspace{0.15cm} $\vcenter{\hbox{\includegraphics[width=0.015\linewidth]{Column.png}}}$}{name=SystemArchitecture,column=2,span=2,row=0}{

\begin{multicols}{2}
    Enterprise Information Management Systems (EIMS) are a structured system that ensures consistency, integration and scalability of data. EIMS relies on a strictly defined life cycle of information management (figure~\ref{fig:lifecycle}). Information across its life cycle is first created before being classified through the use of metadata which declares information about the data based on type, source or sensitivity level. Data is then stored into a tiered repository within the database in a location based on its access frequency or cruciality making it significantly easier to find with enterprise search tools. After data is Securely Stored within the database collaboration tools like Microsoft SharePoint are integrated into the EIMS to enable secure sharing over the internet while governance mechanisms ensure that data access is regulated within the system throughout its life cycle before its eventual disposition.

In conclusion, Databases in Specialised Software Systems are everywhere. This is because, in many cases, commercial software may not be a viable solution to an issue, especially in secure places like the aforementioned subjects where these systems may be deployed. However, there is now an ethical weakness. Specialised Software Systems can be developed indefinitely and will become astronomical in size, so many people may be storing personal data on these systems, as seen with Microsoft SharePoint, and a data-breach could therefore have real-world damaging consequences. If these systems are accessible by third parties, they need to be built with the consideration of security, as a large database with less-than-sufficient security is generally ethically dangerous. \headerbox{Data Management \hspace{0.15cm} $\vcenter{\hbox{\includegraphics[width=0.015\linewidth]{Server.png}}}$}{name=dataManagement,column=1,row=0,above=conclusion}{

Enterprise Information Management Systems (EIMS) structure how organisations manage data across its lifecycle: Create, Classify, Store, Retrieve, Share, and Govern. By integrating centralised repositories, metadata classification, and enterprise search, these systems reduce data fragmentation and improve accessibility \cite{armbrust2010}. Automated retrieval technologies can reduce document handling time by 40–50\%, significantly improving operational efficiency \cite{davenport2018}. However, large centralised repositories present significant security risks, becoming prime targets for cyberattacks and requiring robust data protection measures.
}

\headerbox{Ethical Issues \hspace{0.15cm} $\vcenter{\hbox{\includegraphics[width=0.015\linewidth]{Ethics.png}}}$}{name=ethics,column=0,below=introduction, span=2, above=references}{

\begin{multicols}{3}
    \large Privacy
    \normalsize
    \\

    Cloud Enterprise Information Management Systems store a large amount of company's data and personal information on online servers which creates ethical concerns because sensitive information can be accessed, shared, or used without the users knowing about it. Protecting privacy also becomes harder because data is being stored in different cloud systems and handled by different service providers. \\ 

    \columnbreak

    \large Responsibility
    \normalsize
    \\

    Cloud systems bring a lot of information about an organisation in one place, due of which, organisations must make sure that data is stored, protected, and used in a safe and responsible way. Weak data management policies can lead to misuse of information, poor security, or breaking privacy laws.

    \columnbreak

    \large Ethical Significance
    \normalsize
    \\
    \\
    Information Management Systems' ease of data collection and analysis requires organisations to use them responsibly, ensuring privacy, transparency, and data protection.  \cite{pearson2013privacy}.
